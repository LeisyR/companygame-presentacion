# CompanyGame · Presentación

Presentación web (un solo archivo `index.html`) de **Simuladores de Negocios Colombia / CompanyGame**.

🌐 **En línea (pública):** https://leisyr.github.io/companygame-presentacion/

---

## Cómo trabajar en VS Code

1. Abre esta carpeta en VS Code (`Archivo → Abrir carpeta...`).
2. La primera vez, VS Code te ofrecerá instalar las **extensiones recomendadas** → acepta.
   - Sirven para ver la presentación **en vivo** mientras editas.
3. Para previsualizar:
   - Clic derecho sobre `index.html` → **"Show Preview"** (extensión *Live Preview* de Microsoft), o
   - Clic en **"Go Live"** (abajo a la derecha) si usas *Live Server*.
4. Edita el texto/estilos en `index.html`. Los cambios se ven al instante en la vista previa.

---

## Cómo publicar los cambios (que se vean en el link público)

El sitio se actualiza solo al subir los cambios a GitHub (rama `main`):

```bash
git add .
git commit -m "describe el cambio"
git push
```

En **1–2 minutos** GitHub Pages actualiza la página pública.
Para verla recién publicada, recarga con **Ctrl + F5** (fuerza recarga sin caché).
